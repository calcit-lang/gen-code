# Upgrade gen-code to Calcit 0.13.77

- Raise the compiler baseline from 0.13.75 to 0.13.77 and pin the JavaScript runtime package to the exact matching version.
- Resolve Calcit modules and JavaScript packages strictly and immutably before compilation.
- Verify the installed compiler and `@calcit/procs` versions before JavaScript generation and the existing Vite production build.
- Preserve application version 0.0.11, prompts, deployment configuration, and public behavior.

## Blocked validation

- Calcit 0.13.77 strict Caps resolution and compiler/runtime verification pass, and canonical formatting leaves the Snapshot unchanged.
- The first project `--check-only` is blocked in `Respo/respo.calcit@0.16.89`: `respo.core/decorate-defcomp` emits `W_FN_ARG_TYPE_MISMATCH` for `calcit.core/update` argument 3.
- The upstream fix is merged on Respo main but is not present in a consumable release; Calcit issue #670 expects the next Respo patch after 0.16.90. This repository must not carry a local workaround.
